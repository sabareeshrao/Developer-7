# Developer-7 — GIS Job Experience World

This repository is a **fictional interview-simulation world** built progressively around a geographic / GIS enterprise.

## Purpose

The goal is to turn job-experience interview questions into one internally consistent project universe instead of inventing a different story for every answer.

The world will grow **one question at a time**. Each question may introduce or refine:
- company/domain context
- project architecture
- Java/Spring Boot implementation
- GIS data flows
- databases and spatial data
- APIs and integrations
- batch/scheduled processing
- testing
- CI/CD and deployment
- production support
- incidents and debugging
- Agile/team/leadership scenarios

## Source banks

- Job-experience progression: **387 questions**
- Master interview bank: **2,308 questions**

## Interaction contract

When the user says **Next**:
1. Take the next unanswered job-experience question.
2. Answer it in chat using the 80/20 learning format:
   > I want to learn about [question]. "Show me only the most important 20% that will help me understand the other 80%."
3. Extend the same fictional GIS world only as much as needed to support that answer.
4. Persist new canon, architecture, code, data, scenarios, and question progress in this repository.
5. Never contradict already-established canon. If a later question requires refinement, document the change.

## Grounding

The fictional world is inspired by the supplied resume's Java/Spring Boot and geospatial-platform background, but repository scenarios are simulation material and should not be represented as factual employment history.
