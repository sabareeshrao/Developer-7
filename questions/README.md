# Question Banks

## Primary progression

The world is built from the dedicated **387-question Job Experience bank** in this exact order:

- [Questions 001–100](job-experience-001-100.md)
- [Questions 101–200](job-experience-101-200.md)
- [Questions 201–300](job-experience-201-300.md)
- [Questions 301–387](job-experience-301-387.md)

## Master interview bank

The supplied master workbook contains **2,308 interview questions** across Java, Spring, architecture, testing, databases, DevOps, cloud, production support, leadership, and related domains.

The 387-question Job Experience bank is the progression used for the fictional GIS world. The 2,308-question bank is a broader reference source and does not change the sequence above.

## Advancement rule

- Current question starts at 1.
- The user can say **Next**.
- Exactly one job-experience question is processed unless the user explicitly requests more.
- The original question wording and numbering remain immutable.
- World-building output for a processed question goes under `world/questions/`.
